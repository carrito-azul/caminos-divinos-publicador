Politica de privacidad

Caminos Divinos Publicador - ultima actualizacion: 9 de noviembre de 2026

Que datos usa

La aplicacion solo accede a la cuenta de YouTube y a la cuenta de Instagram del propio creador de Caminos Divinos, con su autorizacion. Usa los permisos para: subir y programar sus videos, leer la informacion de su canal y leer las estadisticas de sus propias publicaciones (vistas, retencion, alcance).

Como se guardan

Los permisos de acceso (tokens) se guardan cifrados como secretos de GitHub Actions y en el computador del creador. Las estadisticas se guardan en archivos del repositorio del proyecto para analizar que contenido funciona mejor.

Con quien se comparten

Con nadie. Los datos no se venden, no se ceden a terceros ni se usan para publicidad. La aplicacion no accede a datos de otros usuarios de YouTube o Instagram.

Uso de las APIs de Google

El uso de la informacion recibida de las APIs de Google cumple con la Politica de Datos del Usuario de los Servicios de las APIs de Google, incluidos los requisitos de Uso Limitado. Esta aplicacion usa los Servicios de la API de YouTube; consulta los Terminos del Servicio de YouTube y la Politica de Privacidad de Google.

Como revocar el acceso

El acceso se puede retirar en cualquier momento desde la configuracion de seguridad de la cuenta de Google. Al retirarlo, la aplicacion deja de funcionar y los datos guardados se pueden borrar a peticion.
